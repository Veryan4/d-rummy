# cards

A decentralized card games app. Play Rummy or Crazy Eights with other people. Data generated by the users is not stored on a server. Instead the users exchange the data with each other in an encrypted fashion.

See [the blog post](https://v-goodship.medium.com/p2p-zero-trust-card-game-3d7dd11fad5e).
